<h3 align="center">Just a developer who likes clean commits.</h3>

I write Go and Python most days, building backends that talk to PostgreSQL and Redis and hoping the latency stays honest. Lately I keep returning to the same questions — what makes a service boundary actually feel right, when does an abstraction earn its keep, and how much complexity is too much before you're just paying interest on someone else's decision. Distributed systems keep me humble that way; every clean API I design feels less like an achievement and more like a draft I'll revise later.
